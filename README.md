# Amazing Compression Tech

なんと、脅威の圧縮技術  
どんなファイルでも100%のサイズ圧縮を実現

## URL

https://otoneko1102.github.io/amazing-compression-tech/

## 説明

任意の画像/音声/動画ファイルを0byteまで圧縮。  
その圧縮率はなんと「100%」(驚異のInfinity倍圧縮)

> [!Warning]  
> 不可逆圧縮だが無限のサル定理を考えると可逆圧縮かもしれない。  
> ただし、その場合、解凍(復元)までに無限の時間を要する。
